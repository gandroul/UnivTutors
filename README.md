# Psychometric Evaluation of the DUWAS-10 in a Greek Academic Population: Data and Analytic Code

## Overview
This repository contains the anonymized dataset, survey documentation, and statistical code (R scripts) associated with the manuscript:
> **"Psychometric Evaluation of the Dutch Work Addiction Scale (DUWAS-10) in a Greek Academic Population"**

The study evaluates the psychometric properties of the short 10-item Dutch Work Addiction Scale (DUWAS-10) using Confirmatory Factor Analysis (CFA with WLSMV estimator) and Item Response Theory (IRT via Samejima's Graded Response Model) on a nationwide sample of Greek faculty members ($N = 1,168$).
